# Longbow Bench-Tool Reference

The `bench-tool` is a high-performance benchmarking utility designed to stress-test the Longbow storage engine. It provides automated ingestion, indexing, and search benchmarks across various vector dimensions and data types.

## Installation

Build the bench-tool from source:

```bash
go build -o bin/bench-tool ./cmd/bench-tool
```

## Usage

```bash
./bench-tool [options]
```

### Core Options

- `-uri string`: Server address (default: `127.0.0.1:3000`)
- `-dataset string`: Dataset name for the benchmark (default: `bench_go`)
- `-dim int`: Vector dimension (default: 128, max: 3072)
- `-scale int`: Total number of vectors to ingest (default: 1000)
- `-dtype string`: Data type: `float32`, `float16`, `int8`, `uint8`, `int16`, `uint16`, `int32`, `uint32`, `float64`, `complex64`, `complex128`
- `-queries int`: Number of search queries to perform (default: 1000)
- `-workers int`: Concurrent search workers (default: 1)
- `-drop`: Automatically drop the dataset after the benchmark completes

### Advanced Options

- `-json string`: Path to save results in JSON format
- `-tq-bits int`: Bit depth for TurboQuant (2, 4, 8) if applicable

## Benchmark Phases

The tool executes benchmarks in the following sequence:

1.  **Ingestion (DoPut)**: Measures ingestion throughput (vec/s and MB/s).
2.  **Indexing Wait**: Polls the server until background HNSW/Learned Index construction is complete.
3.  **HNSW Search**: Measures Top-K search latency and QPS.
4.  **Flat Search**: Measures brute-force search performance.
5.  **Filtered Search**: Tests SIMD-accelerated metadata filtering.
6.  **GraphRAG Search**: Benchmarks multi-hop graph traversals.
7.  **Learned Index Search**: Validates the performance of the k-NN predictor.
8.  **Geo/Temporal Search**: Stress-tests specialized index paths.

## Example

```bash
# Benchmark 1M vectors, 384 dims, with 16 concurrent workers
./bench-tool -scale 1000000 -dim 384 -workers 16 -drop
```

## Performance Monitoring

During execution, `bench-tool` provides real-time progress for ingestion and indexing. Final results include P50, P95, and P99 latencies for all search types.
