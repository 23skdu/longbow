# Longbow Scripts Directory

This directory contains utility tools for testing, benchmarking, and validating Longbow. All deprecated and redundant shell scripts have been removed to consolidate testing into a unified suite.

## Primary Tools

### `unified_benchmark.py`

The primary benchmark tool for Longbow correctness and performance testing. Runs comprehensive matrix tests across dimensions, data types, and counts. Supports CPU, Metal (macOS), and CUDA (Linux) modes.

**Key Arguments**:

- `--mode`: Backend mode (cpu, metal, cuda, onnx, recommend, deletion, graphrag, exchange, cluster, temporal)
- `--dims`: Comma-separated dimensions (default: 128,384)
- `--counts`: Comma-separated batch sizes (default: 1000,5000,25000,100000,250000)
- `--dtypes`: Comma-separated data types (float32, int8, turboquant8, etc.)
- `--memory`: Maximum memory in bytes
- `--search-modes`: hybrid, dense, sparse, filtered, byid

**Usage**:

```bash
# Run full matrix benchmark suite locally
python3 scripts/unified_benchmark.py --mode cpu,metal --dtypes float32,int8 --dims 128,384 --counts 1000,5000 --search-modes hybrid,dense
```

### `cli_benchmark.py`

Automated blackbox functional testing suite for the `longbow-cli` binary.
It spins up an isolated, ephemeral Longbow server and systematically tests all documented CLI features:

- Namespace and Dataset Management
- Vector and Geospatial Search
- GraphRAG Operations (PageRank, Traversal, Community Detection)
- Temporal Search
- Snapshot, Statistics, and Dropping

**Usage**:

```bash
# Executes the full suite of CLI operations and validates success
python3 scripts/cli_benchmark.py
```

### `summarize_benchmarks.py`

Parses output logs generated by `unified_benchmark.py` to calculate throughputs (vec/s) and detect performance regressions.

### `generate_performance_report.py`

Aggregates JSON performance metrics and outputs detailed markdown reports.

### `verify_temporal_optimization.sh`

Specialized shell script for validating temporal indexing performance and garbage collection overhead.

## Setup

Install Python dependencies before running any Python tools:

```bash
pip install -r scripts/requirements.txt
```

## Binary Paths

The Python scripts assume the Go binaries are built and placed in the project root's `bin/` directory:

- `bin/longbow` (The main server)
- `bin/bench-tool` (The gRPC high-throughput load generator)
- `bin/longbow-cli` (The user-facing functional command-line tool)

```bash
# Build Go tools
go build -o bin/bench-tool ./cmd/bench_io
go build -o bin/longbow ./cmd/longbow
go build -o bin/longbow-cli ./cmd/cli
```
