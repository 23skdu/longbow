1. **Successful Parallelization Recovery**: General `DoGet` scaling now maintains high throughputs (up directly into 1000+ MB/s) up through 25,000 rows. The previously observed performance cliff was successfully resolved by distributing `ArenaAllocator` instances per background download worker goroutine, eliminating `madvise` and allocator mutex lock contention issues.

2. **Dimension Scaling Overhead at 10,000**: For data types scaling past 10,000 items (specifically Float-based nodes), Search QPS experiences structural step-downs (e.g., Dense Search dropping from 1700 to 800 QPS). This matches structural thresholds from adaptive level multipliers which expand node density past that tier to sustain correct recall.

3. **Float32 High-Dim Regression (INVESTIGATING)**: The float32 384 25k regression (~61 MB/s DoGet, ~39 QPS Dense) shows:
