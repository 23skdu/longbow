# Longbow Release 0.1.7

The v0.1.7 release of Longbow represents a foundational leap in processing performance, hardware diversity, and extreme memory efficiency. This release introduces state-of-the-art vector compression via **TurboQuant**, comprehensive **GPU acceleration** (Metal/CUDA), and initial support for **Edge/IoT** devices like Raspberry Pi.

## 🚀 Performance Highlights

The 2026-03-27 performance audit benchmarked Longbow against a 440-case matrix across Apple Silicon and x86_64 architectures.
*   **Peak QPS**: Exceeded **100,000+ QPS** on dense search workloads using optimized NEON kernels (Apple M3 Pro).
*   **Latency**: Sub-millisecond **P50 latency (<0.3ms)** maintained across 128d-768d float32 vectors.
*   **Scalability**: Robust performance scaling for dimensions up to **3072** with dedicated AVX512 and NEON optimization.

## 💎 TurboQuant Extreme Compression

Longbow now features **TurboQuant**, a multi-stage quantization engine designed for high-dimensional embedding spaces:
*   **6-8x Memory Reduction**: Typical 768d vectors reduced from 3072 bytes (Float32) to ~512 bytes.
*   **High Accuracy**: Maintains **>95% search recall** through a combination of:
    *   **SIMD-accelerated FWHT**: Fast Walsh-Hadamard Transform for uniform information distribution.
    *   **PolarQuant**: Recursive polar coordinate quantization.
    *   **QJL Error Correction**: 1-bit Johnson-Lindenstrauss sign correction for residual errors.

## 🥧 Raspberry Pi & Edge Support (Beta)

Longbow 0.1.7 introduces initial support for low-power edge devices:
*   **Cross-Compilation**: Dedicated build targets for **Raspberry Pi Zero** (ARMv6, `build-rpi0`) and **Pi Zero 2W** (ARM64, `build-rpi0-2`).
*   **Low-Memory Mode**: Activating `LONGBOW_LOW_MEM=1` at runtime optimizes the engine for devices with <512MB RAM, focusing on efficient slab allocation and reduced buffer sizing.

## 🛠️ Major Architectural Changes

*   **Comprehensive GPU Abstraction**: Unified backend for Apple Metal (ARM64) and NVIDIA CUDA (AMD64).
*   **GPU Resource Management**: Advanced pooling, automated hardware detection, and circuit breakers.
*   **Hybrid Search Pipeline**: Seamless GPU/CPU execution integration for low-latency similarity search.
*   **IVF-PQ Support**: New indexing infrastructure for tiered quantization strategies.
*   **SIMD Kernel Refactoring**: Rewritten AVX2 and NEON kernels for `int8`/`float32` types for improved throughput.
