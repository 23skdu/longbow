## Analysis

The performance metrics for `float32` fully scale up with efficient linear operations. 
1. **Float32-128-15k** reaches **1155.30 MB/s DoGet** and **7,129 QPS Dense Search**.
2. **Float32-384-15k** speedups were verified in isolated delayed prewarm tests (>500 QPS).

The apparent "collapse" in earlier benchmarks was an **async indexing lag artifact**. Large scale insertion metrics take slightly longer to flush on higher dimensions, causing GET/SEARCH tests to overlap with background indexing loads if executed with brief 5s cooldowns. 

To mitigate, background indexers are now enabled with parallel `runtime.NumCPU()` threads (addressing a `sync.Once` lock sequence issue setup by default), and inner loops in `selectNeighbors` bypass interfaces reflection via fast-paths for float32.
