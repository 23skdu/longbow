# v0.1.8-rc4 Release Notes

## Summary
**99 commits** since v0.1.7 release

## New Features

### Core Engine
- **Learned Indexes (Part 16)**: ML-based index performance prediction using Ollama
- **Streaming/Real-Time Updates (Part 17)**: CDC, WebSocket, MQ exporters
- **SIMD Optimizations**: Blocked functions for uint16/uint32/uint64/int64

### Multi-Tenancy
- **Tenant migration APIs**
- **Tenant-level rate limiting**
- **Tenant-aware metrics**
- **Tenant-specific caching**
- **Tenant resource quotas**

### Security (Part 10)
- **Fine-grained RBAC & API Keys**

### Enterprise Features
- **Data Versioning (Part 8)**
- **Backup & Disaster Recovery (Part 9)**

### API Extensions
- **Part 1.5**: Capacity planning APIs
- **Part 4**: Vectorization infrastructure
- **Part 4.5**: Model versioning
- **Part 7.5**: I/O scheduler
- **Part 10.5**: OAuth/SSO
- **Native support**: int16/int32/int64/uint16/uint32/uint64 queries

### Infrastructure
- **Multi-GPU sharding** with round-robin and load-balancing strategies
- **GPU-accelerated HNSW** index construction

### Performance
- **Float16 support** with ARM NEON SIMD
- Updated benchmarks showing improvements across dtypes
