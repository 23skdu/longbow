# Longbow CPU Performance Matrix

## Executive Summary

Longbow shows exceptional ingestion and search performance across a wide variety of data types and dimensions. The 440-case test matrix demonstrates that the unified engine scales reliably, with standard float32 and specialized TurboQuant types achieving peak throughput on the Apple M3 Pro.

### Key CPU Findings

- **High-Throughput Ingestion**: Standard `float32` ingestion exceeds 300k vec/s for lower dimensions.
- **TurboQuant Dominance**: The specialized `turboquant` data type achieves the highest ingestion rates, peaking at ~600k vec/s (dim=128), nearly 2x faster than standard float32.
- **Search Efficiency**: Search QPS remains high (>1000 QPS) for dim=1536, making it suitable for modern transformer models.
- **Complexity Scaling**: While `complex128` and `float64` introduce more overhead, they maintain stable sub-10ms latencies even at high dimensions.
